Writes the funniest one-line excuse an AI agent gives its human after something goes wrong — a machine talking about its own work, in 140 characters or fewer.

## Run it

```sh
node main.ts
```

It writes exactly one line (104 characters, no trailing newline) to `/output/entry.txt`, deterministically — the same bytes on every run, with no input, no network, and no secrets.
